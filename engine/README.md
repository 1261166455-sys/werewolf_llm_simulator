# werewolf_llm_simulator 狼人杀 LLM 模拟器

A simple game emulated the classic Werewolf game, allowing LLMs to play

一个基于 FastAPI + WebSocket 的狼人杀操作台：6 个座位可以由**真人**和**大模型（LLM）**任意混合占用，可以在浏览器里实时观战、发言、投票和进行夜间行动。

## 功能特点

- **真人 / 模型混合对局**：每个座位单独切换为「真人」或「模型」，也可以让 6 个模型同时自动对战。
- **浏览器操作台**：实时显示发言、投票、夜晚行动与完整文字记录。
- **私有信息隔离**：狼人刀人、预言家验人、女巫用药只有当事人可见，模型只能看到自己该知道的信息。
- **全中文 + 中英切换**：界面、系统提示以及发送给模型的内容都能随时切换语言。
- **导出与回放**：一局结束后可导出存档，之后离线重放整局，**回放不会调用模型、不需要联网**。
- **身份显示开关**：可选择是否公开显示每名玩家的身份。

## 快速开始

### 1. 安装依赖

```bash
cd engine
python3 -m venv venv
./venv/bin/python -m pip install -r requirements.txt
```

依赖只有三项：`fastapi`、`uvicorn[standard]`、`colorama`。

### 2. 配置 API 密钥

在 `engine/` 目录下创建 `ds_key.txt`，写入密钥：

```text
sk-你的密钥
```

也支持键值对写法，可顺便指定模型与接口地址：

```text
api_key  = sk-你的密钥
model    = deepseek-chat
base_url = https://api.deepseek.com/v1
kind     = deepseek
```

> ⚠️ **`ds_key.txt` 已被 `.gitignore` 忽略，请勿提交到仓库。** 密钥只在启动时读入进程环境变量，不会写入磁盘、不会打印到日志，也不会发送到浏览器（页面只知道「有没有密钥」）。

### 3. 启动

```bash
./venv/bin/python run.py
```

脚本会读取密钥、自动挑选空闲端口，并在服务可访问后打开浏览器（默认 <http://127.0.0.1:8000/>）。

## 命令行参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--lang` | `zh` | 界面与提示词语言，可选 `zh` / `en` |
| `--port` | `8000` | 起始端口，被占用时自动向后查找 |
| `--host` | `127.0.0.1` | 监听地址 |
| `--key-file` | `ds_key.txt` | 密钥文件路径 |
| `--no-browser` | 关闭 | 不自动打开浏览器 |

示例（英文界面、9000 端口、不自动打开浏览器）：

```bash
./venv/bin/python run.py --lang en --port 9000 --no-browser
```

## 操作台使用说明

1. **设置座位**：在「模型与座位」中把每个座位设为「真人」或「模型」。
2. **测试连接**（可选）：点「测试连接」确认密钥与网络可用。
3. **开始游戏**：点「新游戏」。轮到真人时页面下方出现输入框；轮到模型时自动请求并显示「模型思考中…」。
4. **观战**：发言、投票、夜晚行动实时刷新。未公开的身份显示为 `??`，可用「公开显示身份」开关随时切换；「显示提示词」可查看发送给模型的完整提示。
5. **导出 / 回放**：一局结束后点「导出本局」保存到 `engine/replays/`；在「导出文件」下拉框中选择后点「回放所选」即可离线重放，也可点「回放上一局」直接重放刚结束的一局。
6. **切换语言**：页面右上角可随时切换中英文，已经显示在屏幕上的记录也会同步翻译。

## 游戏规则

- 6 名玩家（P0–P5），角色随机分配：**狼人 ×2、预言家 ×1、女巫 ×1、平民 ×2**。
- **夜晚顺序**：狼人刀人 → 预言家验人 → 女巫用药（可救可毒）。
- **白天**：依次发言 → 投票放逐；平票时本轮无人出局。
- **胜负判定**：
  - 好人胜利：存活狼人数为 0。
  - 狼人胜利：预言家与女巫都出局，**或**两名平民都出局。
  - 平局：超过 10 天仍未分出胜负。

## 常见问题

**Q：启动时提示「未找到密钥」，模型座位不动？**
A：确认 `engine/ds_key.txt` 存在且第一行是完整密钥（`sk-` 开头）。真人座位不受影响，可以先只用真人测试。

**Q：端口被占用？**
A：脚本会自动使用之后的空闲端口，请以启动信息中「页面」那一行的地址为准。

**Q：模型返回的内容解析失败？**
A：程序会自动尝试修复 JSON，若仍不合法则退回一个合法动作，不会卡死。可点「测试连接」查看具体错误原因。

**Q：回放需要联网或密钥吗？**
A：不需要。回放是本地重新推演，完全不调用模型。
